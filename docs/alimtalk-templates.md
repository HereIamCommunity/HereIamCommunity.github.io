| 변수 | 값 (구글 시트 열) |
|---|---|
| `#{이름}` | C 이름 |

| `#{일시}` | F 일시 |

## 발송 규칙

- 게스트 메시지(1~6): 템플릿 ID env가 없으면 **발송하지 않는다**(검수 전 차단). 있으면 알림톡, 실패 시 문자 대체.
- 호스트 메시지: 템플릿과 무관하게 **항상 문자**로 보낸다(운영 알림). `KAKAO_TEMPLATE_HOST`가 있으면 알림톡.
- cron 메시지(7~8): 템플릿 ID env가 있으면 알림톡(실패 시 문자), 없으면 **기존처럼 문자**로 보낸다(운영 중인 안내라 끊지 않는다).
